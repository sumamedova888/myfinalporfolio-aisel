# Aisun Mamedova — Portfolio

Premium personal portfolio website for Aisun Mamedova — AI-Powered Growth Marketing Manager.

Built with Next.js, React, Tailwind CSS, Framer Motion, and Lenis smooth scroll.

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- Lenis
